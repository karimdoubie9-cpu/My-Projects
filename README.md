# My Projects

Academic and engineering projects from my M.Sc. in Space Engineering at Politecnico di Milano, covering spacecraft guidance and navigation, attitude dynamics, mission design, and control and estimation of aerospace systems.

Author: **Karim Ahmed Mohamed Doubie**

## Projects

| Folder | Course | Description |
|---|---|---|
| `Space Guidance Project` | Spacecraft Guidance and Navigation | Lambert problem in the Earth–Moon CR3BP, low-thrust guidance around Eros, impulsive transfer to a Distant Prograde Orbit for the LUMOS mission |
| `Space Navigation Project` | Spacecraft Guidance and Navigation | Uncertainty propagation (LinCov, UT, Monte Carlo), batch orbit determination with ground stations, and UKF navigation with GNSS and AI-based measurements |
| `Space System Engineering and Operations` | Space System Engineering and Operations | Reverse engineering of NASA's LADEE lunar mission, with subsystem re-sizing compared against real values |
| `Spacecraft Attitude Dynamics Project` | Spacecraft Attitude Dynamics | Attitude dynamics and control of a spacecraft |
| `Adaptive and Autonomous Aerospace Systems Project` | Adaptive and Autonomous Aerospace Systems | Adaptive control (PBMRAC) of a hexacopter for package delivery, with RRT* route planning and minimum-snap trajectories |
| `Digital Control Project` | Digital Control Technology for Aeronautics | Digital cascade controller for a flexible transmission, with a hybrid Simulink simulation of sensors, ADC and DAC |
| `System Identification Project` | Estimation and Learning in Aerospace | Grey-box identification of a multirotor UAV's longitudinal dynamics, with sensitivity and Monte Carlo analysis |

Each project folder has its own `README.md` with the details.

## Tools

MATLAB / Simulink, SPICE, LaTeX.
