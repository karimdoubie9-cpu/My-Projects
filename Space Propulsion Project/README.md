# CubeSat Propulsion: MEMS Units

Project for the **Space Propulsion** course (M.Sc. Space Engineering, Politecnico di Milano, A.Y. 2024-25, Montemagno Group).

Team: Arturo Calderazzi, Matteo Candita, Karim Ahmed Mohamed Doubie, Riccardo Cislaghi, Mohamed Ghoraba, Riccardo Giovenzana, João Lemes Gribel Soares.

## About

Design and comparison of three micro-propulsion systems for CubeSats built with MEMS technology: a solid propellant microthruster array, a cold gas thruster and a vaporizing liquid microthruster. Each system is sized from its requirements, then tested with a Monte Carlo analysis that models manufacturing and operating uncertainties. The three solutions are finally compared with each other and with real data.

## Contents

| Section | Topic |
|---|---|
| 1 | Introduction: micro-propulsion systems, micro-nozzle fundamentals (Reynolds number, expansion ratio, cross-sectional profile) and design methodology |
| 2 | Solid propellants: configuration, aluminized AP-HTPB propellant characterization, nozzle, grain and array sizing, Monte Carlo simulation |
| 3 | Cold gas thruster: system overview and modelling approach, nominal design of the components, power requirements, Monte Carlo analysis |
| 4 | Vaporizing liquid microthruster: thermophysical behaviour of water, vaporizing chamber, heater power and energy, nozzle, injector, tanks, regulating valve and pressure losses, Monte Carlo analysis |
| 5 | Comparative analysis: data analysis of the three systems, comparison with real data, conclusions |

## Tools used

MATLAB, NASA CEA (thermochemical equilibrium), CoolProp (fluid properties), LaTeX (report).
